# hasplabs.github.io

The Hasp Labs website, served by GitHub Pages from the root of `main`. Plain HTML and one stylesheet; no build step and no Jekyll (`.nojekyll`).

- `/` -- Hasp Labs and its apps
- `/fortyfivehard/privacy/` -- the 45 Hard privacy policy (the App Store listing's Privacy Policy URL)
- `/fortyfivehard/support/` -- 45 Hard support (the App Store listing's Support URL)

Edit the HTML, commit to `main`, and GitHub Pages publishes it within a minute or two.
