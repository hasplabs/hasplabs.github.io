# hasplabs.github.io

The Hasp Labs landing page, served by GitHub Pages from the root of `main`. Plain HTML and one stylesheet; no build step and no Jekyll (`.nojekyll`).

Each app's support and privacy pages live in that app's own repo and are published under this domain as a project site:

- QR Trust: `hasplabs/qrtrust` at https://hasplabs.github.io/qrtrust/
- 45 Hard: `hasplabs/fortyfivehard` at https://hasplabs.github.io/fortyfivehard/

Edit the HTML, commit to `main`, and GitHub Pages publishes it within a minute or two.
